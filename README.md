# Joi Emmanuel Holgado — Portfolio

A responsive personal portfolio built with React, TypeScript, and Vite. The supplied résumé provides the professional experience, skills, and education; both supplied portraits appear in the site.

## Run locally

Use a current Node.js LTS release, then run:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To create and preview the production build:

```sh
npm run build
npm run preview
```

The production files are generated in `dist/`.

## Content and assets

Keep professional titles, employers, dates, qualifications, and skills consistent with the supplied résumé. Add projects, results, or other claims only when Joi supplies supporting details.

The original supplied files are available under `public/assets/`:

- `joi-portrait-primary.jpg`
- `joi-portrait-secondary.jpg`
- `joi-emmanuel-holgado-resume.pdf`

Update portfolio copy and layout in the React source under `src/`. Replace the asset files when updating portraits or the downloadable résumé.
